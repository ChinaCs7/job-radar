# 发布说明草稿与检查

## 仓库简介

本地运行的多信源求职信息聚合工具：独立求职方案、岗位管理、定期检索与可选 AI Agent。Electron + FastAPI + React。

建议 Topics：job-search、job-aggregator、career、python、fastapi、electron、react、ai-agent、local-first。

## 首次公开发布文案

求职雷达将招聘平台、公司官网、社区和海外 / 远程站点的岗位线索收集到本机。你可以按求职者、方向和城市创建独立方案，定期检索、查看原文、收藏和记录投递进度。

基础功能无需模型 key；配置自己的 DeepSeek key 后，可使用 AI 整理、匹配理由、总结，以及按简历设计方案的流式 Agent。

当前为早期源码版本，Windows 是主要验证环境。部分信源仍在适配，不保证全站覆盖或岗位有效性，暂不提供安装包。开始使用请看 README 和逐信源状态。

## 公开仓库前

- 确认 main 包含所需代码与文档，并与预期远程提交一致。
- 确认 MIT 许可符合自己的发布意图，第三方引用与声明保留。
- 检查整个 Git 历史中的 key、Cookie、数据库和个人资料；忽略规则不删除历史文件。
- 确认历史提交的作者名和邮箱可以公开。发布仓库历史会公开这些元数据。
- 确认截图、示例与 Issue 均使用虚构或已脱敏数据。
- 确认 data、work、.env 与浏览器登录态没有进入待发布内容。
- 检查仓库可见性、Issue 设置和私密漏洞报告入口。改变可见性应单独确认。
- 不要把仅修改 package.json 版本号当作完成安装包构建或跨平台验收。

首次源码发布可以将本页文案用于 GitHub Release；没有实际创建标签或 Release 前，不宣称已经发布版本。
