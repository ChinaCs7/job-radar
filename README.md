# 求职雷达（job-radar）

在自己电脑上运行的求职信息聚合工具。设好关键词、城市、薪资这些条件后，它按你定的频率持续检索多个招聘平台、社区和海外站点，把结果整理到一个可以筛选的页面里。每条岗位都带原始链接和信源。

- **桌面应用**：设置条件、管理信源和频率、登录账号、查看运行状态、和 AI 助手对话
- **结果页**：在系统浏览器里打开，可以按天、平台、类型、地区、匹配分、状态筛选，也能导出成单个 HTML 文件，发到手机上看
- **本机优先**：账号登录态、API key、数据都只存在你的电脑上

## 信源

共 24 个，在「信源与频率」里逐个开关、设间隔。标「浏览器」的用应用自带的专用 Chrome 打开网页检索（只旁听页面自己的请求、或读取渲染好的页面，不注入脚本）。

| 分组 | 信源 | 方式 | 需要 |
|---|---|---|---|
| 招聘平台 | Boss 直聘 | 浏览器，旁听搜索接口 | 登录 |
| | 猎聘、前程无忧 | 浏览器，旁听搜索接口 | — |
| | 智联招聘 | 浏览器，读搜索结果页 | 登录 |
| | 拉勾、58 同城 | 浏览器，读搜索结果页 | 首次手动过验证 |
| | 牛客 | 浏览器，读搜索结果页 | — |
| 公司官网 | 腾讯、字节跳动、小米、美团、网易、米哈游 | 直接请求官网接口；用飞书招聘的公司可以自己添加 | — |

海外信源在界面里都标了「海外」，结果页也能按国内 / 海外 / 远程筛。

试过但这版没接的：百度（直接弹验证码）、阿里 / 京东 / 华为 / 拼多多官网（没找到能直接用的查询接口）、快手官网（接口不带关键词）。

Boss 直聘的采集方式参考了 [eatmoreduck/boss-zhipin-scraper](https://github.com/eatmoreduck/boss-zhipin-scraper)（MIT），城市编码表 `backend/app/data/boss_city_codes.json` 也来自这个项目。

## 去重

同一个岗位在多个平台出现时（按「公司 + 岗位名」判断，公司名先归一化，例如「腾讯科技（深圳）有限公司」和「腾讯 · CSIG」都算「腾讯」；有 AI 时再用 AI 给的公司简称），结果页只显示一条，标「N 个平台都有」，其他平台的链接放在「另见」里；筛选里有「多平台都有」。

## AI（可选，DeepSeek）

填了 key 以后（调用时关闭思考模式，省钱也更快）：
- 新岗位自动整理成统一字段，判断是不是招聘信息，并按你的条件打 0–100 的匹配分、写理由
- 结果页可以生成「这一天的总结」
- AI 助手通过只读工具查询本地数据库来回答问题，比如「今天最适合我的 3 个岗位」

不填 key 也能用，只是没有上面这些功能。全网搜索用必应，不需要 key。

「AI 用量」页记录每次调用的 token 数和估算花费（按 DeepSeek 官网价格，区分高峰 / 空闲时段），按天、按用途汇总。参考：整理 10 条岗位约 ¥0.005（空闲时段），高峰翻倍。

## 开发运行

需要 Python 3.11+、Node 20+、Chrome（或 Edge）。

```bash
# 后端
cd backend
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt   # macOS / Linux: .venv/bin/pip

# 界面
cd ../ui
npm install
npm run build          # 生成 ui/dist，后端直接提供这些页面

# 桌面应用
cd ../desktop
npm install
npm start              # 拉起后端，打开窗口
```

改界面时可以用热更新：先运行 `cd ui && npm run dev`，再运行 `cd desktop && npm run dev`（窗口加载 Vite 开发服务器，后端固定使用 17860 端口）。

数据目录：开发时是项目下的 `data/`；打包后是 `%APPDATA%/求职雷达/data`。

## 目录

```
backend/app/
  main.py          本地服务（FastAPI，只监听 127.0.0.1）
  scheduler.py     调度：每个信源单独计时，间隔随机浮动；被风控就暂停，不重试
  pipeline.py      一次检索的流程：采集 → 筛选 → 去重入库 → AI 整理
  collectors/      各信源的采集器
  browser.py       专用浏览器（直接用 CDP，不注入脚本）
  llm.py           DeepSeek：整理、总结、AI 助手（工具调用）
  db.py            SQLite
ui/                React + Vite；index.html 是桌面界面，report.html 是结果页
desktop/           Electron 外壳：拉起后端、托盘常驻、在系统浏览器打开链接
```

## 使用须知

- 只供个人求职使用。请遵守各平台的用户协议，不要调高频率，也不要把数据拿去转卖。
- Boss 等需要登录的平台有封号风险：默认间隔 2 小时，夜间暂停；一旦被要求验证就自动暂停，等你人工处理。
- RemoteOK 的接口条款要求注明来源并链接回原页面，结果页里每条都带了原始链接和信源。
